# Tab Hammer

A Chrome extension for seeing and organizing every open window and tab as an outline, in its own window. A spiritual successor to Tabs Outliner, built to fix its annoyances.

## Develop

    npm install
    npm run build          # outputs dist/
    npm run gate           # all checks

Load it in Chrome: `chrome://extensions` → Developer mode → Load unpacked → pick `dist/`. Click the toolbar icon to open Tab Hammer.
